Description:

public abstract class PlayerMode : Object

Abstract class of player mode. Player can work with flow (radio), track list, local track list. Every mode autoconnect to `Player.queue_changed` and `Player.nead_changed` signals.

All known sub-classes:
  • PlayerEmpty
  • PlayerFlow
  • PlayerLocal
  • PlayerShufflable
  • PlayerTrackList
